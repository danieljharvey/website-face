## What do we mean here?

A simple sorting query, `SELECT name FROM places ORDER BY name DESC` might return `['zoo','shop','horse museum']`.

Ordering by `name ASC` instead would give us `['horse museum', 'shop', 'zoo']`.

We can order by multiple columns too:

```sql
SELECT firstname, surname FROM people ORDER BY firstname, surname
```

Might return:

```json
["Bill", "Bailey"],
["Bill", "Nighy" ],
["Tim",  "Allen" ],
["Tim",  "Burton"]
```
